# AI Image Classifier Web App

An AI-powered **Image Classification Web Application** that predicts image categories using a Convolutional Neural Network (CNN).

This project demonstrates practical skills in **Machine Learning, Computer Vision, API development, and AI model deployment** using Python and TensorFlow.

---

# Project Overview

This application allows users to upload an image and receive a prediction generated by a trained deep learning model.

The CNN model was trained using TensorFlow/Keras and integrated into a backend API to enable real-time image predictions.

The project is designed as a **portfolio-ready AI project** showcasing the full workflow from **data preprocessing → model training → model deployment**.

---

# Features

* Image classification using Convolutional Neural Networks (CNN)
* Image preprocessing and normalization
* Data augmentation for improved generalization
* Model training using TensorFlow/Keras
* Image prediction API using FastAPI
* Model performance visualization
* Ready for deployment

---

# Model Architecture

The model uses a simple CNN architecture:

* Conv2D Layer (32 filters)
* MaxPooling Layer
* Conv2D Layer (64 filters)
* MaxPooling Layer
* Flatten Layer
* Dense Layer (128 neurons)
* Dropout Layer (0.5)
* Output Layer (Sigmoid activation)

This architecture is designed for **binary image classification tasks**.

# Installation

Clone the repository

```
git clone https://github.com/your-username/ai-image-classifier.git
```

Move into the project directory

```
cd ai-image-classifier
```

Install dependencies

```
pip install -r requirements.txt
```

---

# Train the Model

Run the training script to train the CNN model.

```
python train_model.py
```

The trained model will be saved as:

```
model/image_model.h5
```

---

# Run the API Server

Start the FastAPI server

```
uvicorn api.main:app --reload
```

Open the API documentation:

```
http://127.0.0.1:8000/docs
```

---

# API Endpoint

POST /predict

Upload an image file and the model will return the predicted class.

Example Request:

```
POST /predict
```

Example Response:

```
{
  "prediction": "Cat",
  "confidence": 0.94
}
```
